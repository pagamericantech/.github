# .github

Default community health files for the PagAmerican organization.

Files in this repository apply to every repository in the organization that does not define its own version, as described in the [GitHub documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Contents

- `profile/README.md`: the README displayed on the organization's public profile page.
- `.github/ISSUE_TEMPLATE/`: default issue templates for all repositories.
